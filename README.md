

Репозиторій містить виконання завдань другої лабораторної роботи з дисципліни. Кожне завдання реалізовано в окремому файлі та повністю відповідає вимогам.

## Структура проєкту
* `task1.py` — Ієрархія класів та поліморфізм.
* `task2.py` — Інкапсуляція, property, валідація та name mangling.
* `task3.py` — Магічні методи та перевантаження операторів (`__str__`, `__repr__`, `__add__`, `__sub__`, `__eq__`, `__abs__`).
* `task4.py` — Абстрактні класи (`abc.ABC`) та композиція з делегуванням.
* `task5.py` — Патерн проєктування (Strategy) з демонстрацією розширюваності.

## Інструкція запуску
Для запуску будь-якого завдання виконайте відповідну команду у терміналі:
```bash
python task1.py
python task2.py
python task3.py
python task4.py
python task5.py
